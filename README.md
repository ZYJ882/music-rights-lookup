# music-rights-lookup

一个用于核查歌曲正版在架平台、歌曲详情、版权归属（OP/SP）以及原版/翻唱版本区别的 Manus Skill。

## 内容

- `SKILL.md`：Manus 技能说明与工作流程
- `scripts/music_search.py`：免登录查询网易云音乐、QQ 音乐、酷狗音乐
- `references/platforms.md`：平台接口状态与查询注意事项
- `references/copyright-guide.md`：OP/SP、证据分级与版权核查要点

## 使用边界

本技能只做公开信息的只读核查，不处理账号密码、不自动登录、不下载受版权保护的音频。
