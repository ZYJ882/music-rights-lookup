# 版权核查要点与证据分级

## 一、OP / SP 是什么（识别版权链的钥匙）

| 缩写 | 全称 | 含义 |
|------|------|------|
| **OP** | Original Publisher | 原始版权方（词曲著作权人/其公司） |
| **SP** | Sub-Publisher | 代理版权方（被授权代为管理、分发的公司） |

平台歌曲页/歌词文件头常直接写明，例：
```
OP: 青桔音乐
SP: 银河方舟
```
**这一行信息比任何百科都可靠**，核查时优先从平台页正文抓取。

## 二、常见版权方速查（本会话已核实的真实案例）

| 歌曲 | 版权方 / 发行方 | 类型 |
|------|----------------|------|
| 李荣浩《戒烟》 | Warner Music Taiwan / 北京 Young Music | 国际三大（华纳音乐集团，**非**华纳兄弟影业） |
| 陈奕迅《最佳损友》 | 环球音乐集团（厂牌：新艺宝 Cinepoly） | 国际三大（环球） |
| 福禄寿《我用什么把你留住》 | 北河三音乐（摩登天空旗下厂牌） | 独立厂牌 |
| 郑润泽《瞬》 | OP 青桔音乐 / SP 银河方舟（字节跳动旗下） | 艺人公司 + 流量厂牌组合 |
| 蔡诗芸《雨过后的风景》 | OP Phatt Choy Productions / SP 五十环音乐 Straight50 | 独立 + 代理 |
| 王贰浪《把回忆拼好给你》 | 原曲 TV Tokyo Music（东京电视台音乐）+ 环球音乐版权中国代理；中文版网易云《听，海风》企划发行 | **日文原曲授权翻唱** |
| 刀酱《5:20AM》 | 网易子弹 / 青云 LAB（网易云）；原唱 Soldier | 网红单曲，QQ/酷狗曾为侵权重灾区 |

> 注意区分 **华纳音乐集团（唱片）vs 华纳兄弟（电影）**：两者独立运营，常被混为一谈。

## 三、翻唱 / 填词改编的版权特殊性（常被误解）

| 行为 | 法律属性 | 是否需要事先授权 |
|------|---------|----------------|
| 单纯翻唱录成录音制品 | 可走**法定许可** | 无需事先许可，但须在两个月内按标准付酬 |
| **中文填词（改编歌词）** | 涉及**改编权** | **必须事先取得许可**，法定许可不覆盖改编权 |
| 公开传播 / 商业演出 / 短视频商用翻唱 | 涉及表演权、信息网络传播权 | **必须授权** |
| 改成 DJ 版 / Remix | 擅自改编 | 属侵权，情节严重可涉刑 |

**推论**：像《把回忆拼好给你》这种"日文原曲 + 中文填词"的歌，因涉及改编权，**正规发行方必然是事先拿到授权的**——所以官方版本不是"先上车后补票"。

## 四、「先上车后补票」现象（真实存在，但要分清场合）

- 人民网 2019 年报道直认：翻唱圈普遍"先上车、后补票"，即**火了才去谈授权**；大量未被原唱知晓的翻唱处于"民不举官不究"状态（但这不等于不侵权）。
- **分布**：官方发行版 = 先授权；短视频/民间翻唱 = 常见先上车后补票；盗版下载站 = 从不补票。

回答此类质疑时必须**分层**：区分"官方发行版本"与"民间翻唱"，不要一概而论。

## 五、证据强度分级（写进每一份回答）

| 级别 | 来源类型 | 例子 |
|------|---------|------|
| ★★★ | 平台一手页/接口、国际平台 ©℗ 署名、版权方官方账号 | QQ音乐 detail 页、Spotify © 署名、环球音乐官微引流链接 |
| ★★ | 百科词条（多源一致）、行业媒体报道 | 百度百科、凤凰网《先声周报》 |
| ★ | 聚合营销文、论坛、社区经验 | 今日头条"全平台渠道解析"、盗版资源站 |

**规则**：
- 结论必须至少有一个 ★★★，或 ≥2 个相互独立的 ★★。
- 只有 ★ 来源时：**只能说"据称/待核"，不得当作事实陈述**。

## 六、事实 / 推断 / 传言 三分法（强制标注）

| 类别 | 处理方式 |
|------|---------|
| **事实** | 有 ★★★ 或多源 ★★ 支撑，直接陈述并附来源 |
| **推断** | 我的推理（如"误传成因可能是气质接近"），**必须明确标注"这是我的推断，非官方说法"** |
| **传言** | 社区/论坛说法，**只能标注为传言，绝不写成事实** |

## 七、透明说明（每次回答必带）

必须写明：
1. **已检索**了哪些渠道；
2. **未执行**什么（如：未核验登录态、未拿到授权合同原文、未验证能否播放）；
3. **矛盾点**分别列出，不强行统一；
4. **核查时间**（在架状态会变）。
